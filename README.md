# How the app works
This app uses regex to extract data from `raw-text.txt` file that follow certain patterns that for valid: 
    - Emails
    - Credit card numbers
    - Hashtags
    - Urls
    - Official alu email adresses
    - ALU alumni email addresses
    - ALU si email addresses

# Runnig the app
## prerequisite
To run this app you have to have python3 installed in your environment
## steps
1. Clone the repo from github
2. In the terminal, navigate to the folder with `main.py` file 
    `cd src`
3. Command to run the app   
    `python3 main.py`
